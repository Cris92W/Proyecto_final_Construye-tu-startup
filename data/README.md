# Datos

| Archivo | Qué es | Fuente y fecha |
|---|---|---|
| `entidades_oficiales.csv` | Dominios oficiales y palabras clave de bancos, cajas, billeteras, couriers, telefonía y entidades del Estado. Sirve para saber si un link es oficial o imita a una entidad. | Curada a mano el 2026-11-09. Se comprobó que cada dominio existe y responde. **Revisar antes de cada versión.** |
| `registro_sbs.csv` | *(pendiente)* Nombres de empresas supervisadas o registradas en la SBS, con columnas `nombre,tipo,fuente,fecha`. | La web de la SBS bloquea las consultas automáticas, así que se descarga a mano desde el navegador y se guarda con su fecha. |

No hay datos personales en esta carpeta. Los ejemplos de la app están recreados a partir de modalidades difundidas públicamente, con nombres, números y cuentas ficticios.
